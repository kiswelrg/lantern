# lantern example

This folder is a real directory committed with lantern (every other entry in `sites/`
is a symlink). It exists to show, and smoke-test, what a hosted doc can do.

- [Features](features.md): code, tables, task lists, raw HTML, images, footnotes, diagrams
- [Paper style](paper.md): the same renderer with `style: paper`
- [Showcase](showcase.html): a plain `.html` page served as-is
- [notes/](notes/): a folder without a README gets a file listing
